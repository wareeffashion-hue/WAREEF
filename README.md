# ثيم وريف · Wareef Theme

ثيم أزياء فاخر لمنصة سلة (Twilight)، مبني على ثيم «رائد» الرسمي (MIT) ومصمم للعبايات والأزياء العربية.

## المزايا
- طابع بصري قابل للتبديل (فاخر أحادي، بسيط، ناعم، جريء) ووضع داكن بزر في الأعلى.
- نظام حركة سينمائي (ظهور تدريجي، كلمات تصعد، بارالاكس، شرائط متحركة، عدادات، عد تنازلي) يحترم إعداد تقليل الحركة.
- عناصر رئيسية جديدة بأسماء تبدأ بـ «w-»: واجهات سينمائية، قصص بأسلوب سناب، لوك بوك قابل للتسوق، عروض بعد تنازلي، وغيرها.
- صفحة منتج محسّنة: دليل مقاسات، ملاحظة توصيل، مزايا الثقة.

## التطوير
```bash
pnpm install
pnpm run schema       # يولّد twilight.json من src/schema
pnpm run production   # يبني الأصول في public/
node tools/lint-twig.mjs                 # فحص قوالب Twig
node tools/preview.mjs w-hero-cinematic  # معاينة محلية لعنصر (صور في tools/.preview)
```
دليل كتابة العناصر: `tools/COMPONENTS-GUIDE.md`.
