# خطّان… وبداية عالم أرسلان 💙🦁

فيديو ستوري سناب (1080×1920، ‏9:16، ‏30fps، نحو 52 ثانية) لتهنئة مولود «أرسلان».

- `arslan-story.mp4` — الفيديو النهائي مع الموسيقى.
- `index.html` + `story.js` — المشاهد مرسومة SVG؛ افتح `index.html` في المتصفح للمعاينة الحيّة.
- `assets/` — الشعار مقسّمًا (الشبل `lion.png`، الاسم `name.png`، الشعار كاملًا `logo.png`) والخطوط.
- `music.py` — يولّد موسيقى صندوق الموسيقى والمؤثرات المتزامنة مع المشاهد.
- `capture.mjs` — يلتقط الإطارات عبر Playwright ويصدّرها بـ ffmpeg.

## إعادة التصدير

```bash
pip install numpy imageio-ffmpeg
python3 music.py music.wav
FFMPEG=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
FFMPEG=$FFMPEG node capture.mjs video silent.mp4 30
$FFMPEG -i silent.mp4 -i music.wav -c:v copy -c:a aac -b:a 192k -shortest arslan-story.mp4
```

## المشاهد

| الوقت | المشهد |
|---|---|
| 0–4 ث | شريحة الفحص، يظهر الخط الثاني ويتوهّج |
| 4–6 | الأم تبتسم، والخط يتحوّل خيطًا مضيئًا يلتف حول إصبعها |
| 6–12 | صفحات الأشهر التسعة تدور، تتحوّل نجومًا تدخل البطن، وطبعة كف الشبل |
| 12–18 | نافذة السونار: الشبل نائم على الهلال، يستيقظ، يضغط بأنفه ويسحبنا للداخل |
| 18–24 | مجرّة أرسلان، يسحب الخيط فتنجمع المجرّة كرةً وينفخ فيها |
| 24–31 | البطن فقاعة حريرية، ثلاث خدوش، عين الشبل، الستارة تنفتح وانفجار الفرح |
| 31–36 | الأم تحتضن المولود، والخيط ينسج «أرسلان» ولؤلؤة في نقطة النون |
| 37–44 | عبارات الحمد |
| 44–49 | المهد والمعلّقة والدعاء |
| 49–52 | يد المولود تمسك الخيط الأزرق |
